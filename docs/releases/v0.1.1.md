# vega-paper v0.1.1

Custom theme JSON files and Release workflow fix for Intel macOS builds.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Pin this version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.1.1
```

### Supported platforms

| Asset | Platform |
|-------|----------|
| `vega-paper-0.1.1-darwin-arm64.tar.gz` | macOS Apple Silicon |
| `vega-paper-0.1.1-darwin-x64.tar.gz` | macOS Intel |
| `vega-paper-0.1.1-linux-x64.tar.gz` | Linux x64 |

## Highlights

- **Custom themes (Phase 4b):** `--theme path/to/theme.json` on `render` and `infer`; `themes show` for JSON files
- Theme file format: required `config` (Vega-Lite config object) plus optional metadata
- Example: [`examples/custom-theme/`](../../examples/custom-theme/)
- **Release CI:** `darwin-x64` builds on `macos-15` (replaces unavailable `macos-13` runners)

## Upgrade notes

Built-in theme names and behavior are unchanged. To use a lab or venue theme, add a JSON file and pass its path to `--theme` instead of forking the repo.
