# vega-paper v0.2.0

New `template` command for structured ML paper figures (benchmark heatmap, Pareto frontier, scaling law, calibration curve, violin, ECDF, multipanel), a layered shaded band for `infer --error-band`, opt-in ML lint rules, and a CSV number-parsing fix that makes generated specs safe for datum arithmetic.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Pin this version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.2.0
```

## Highlights

### `template` command (new)

Seven layered ML-figure builders that `infer` cannot express, all emitting committed-spec-friendly Vega-Lite (`data.url` + `format.parse`, exact sizing, theme-controlled color):

- `benchmark-heatmap` — rect + value labels, optional `--highlight-best` outline per column
- `pareto-frontier` — points + computed non-dominated frontier overlay, log-x support
- `scaling-law` — line + optional log/linear regression fit per family
- `calibration-curve` — reliability diagram with diagonal reference and `--ece` annotation
- `violin` — per-category mirrored kernel density; the shared extent is padded past the data so every violin tapers instead of clipping; `--bandwidth` tunes smoothing
- `ecdf` — per-group cumulative proportion as a step curve, pinned to [0, 1]
- `multipanel` — compose existing `.vl.json` files with `(a)`/`(b)` panel labels via `--panel <spec>:<label>[:<title>]`

`--out` renders and writes a `template` figure-meta sidecar with the full option snapshot.

### Shaded error bands

`infer --chart line --error-band <field>` now emits a layered `errorband` + `line` spec (shaded uncertainty band) instead of a bare `yError` encoding.

### CSV number parsing fix

Generated specs referencing a CSV via `data.url` now declare numeric columns in `data.format.parse`, and `--inline-data` embeds numbers as numbers. Previously CSV values reached Vega-Lite as strings; marks that do datum arithmetic (error bands) silently collapsed to nothing.

### ML lint domain (opt-in)

`lint --domain ml` adds four warning rules for ML paper figures: `ml-panel-label-missing`, `ml-crowded-labels`, `ml-too-many-series`, `ml-log-scale-candidate`. Data-dependent rules load rows from the spec's local CSV `data.url`. Default `lint` is unchanged.

### Examples and docs

- New example folders: `ablation-bar/`, `benchmark-heatmap/`, `run-distribution/` (boxplot, points overlay, violin, ECDF over 20 seeds), `pareto-frontier/`, `scaling-law/`, `calibration-curve/`, `multipanel-paper-figure/`
- Gallery previews for every new figure in [`examples/README.md`](../../examples/README.md)

## Upgrade from v0.1.5

- Re-run `install.sh` or pin `--version 0.2.0`.
- Regenerate committed specs to pick up `data.format.parse` and the layered error band: `bun run infer:examples && bun run template:examples` (repo workflows), or re-run your own `infer`/`template` commands.
- `vega-paper --version` now reports the release version.

## Breaking changes

- `infer --chart line --error-band <field>` output changed from a single-mark spec with `encoding.yError` to a layered `errorband` + `line` spec. Downstream tooling that inspects the emitted spec shape must handle the `layer` array. Rendered output is the intended shaded band (the previous shape did not render a visible band).
