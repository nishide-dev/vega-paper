# vega-paper v0.2.0

Built-in theme **series colors** now use curated palettes with documented sources:

- **Paper:** IBM Carbon categorical, Financial Times lineWeb
- **Web / dark:** Catppuccin Latte and Mocha

Theme **names** are unchanged; rendered SVG colors will differ from v0.1.x.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

## Highlights

- Palette registry in `@vega-paper/themes` with attribution metadata
- `vega-paper themes show <name>` prints `paletteId` and source URL
- See [docs/palettes.md](../palettes.md) for hex values and theme mapping
- Regenerated [examples/theme-samples/](../../examples/theme-samples/) as visual baseline

## Upgrade note

Re-render figures after upgrading if you rely on exact series colors. Use `themes show <name> --json` to pin config.
