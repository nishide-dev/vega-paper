# vega-paper v0.1.3

Built-in theme **series colors** now use curated palettes with documented sources (IBM Carbon, Financial Times lineWeb, Catppuccin Latte/Mocha). Theme **names** are unchanged; rendered SVG colors will differ from v0.1.2.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Pin this version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.1.3
```

## Highlights

### Curated palettes (Phase 4c)

- Palette registry in `@vega-paper/themes` with attribution metadata
- **`vega-paper themes show <name>`** prints `paletteId` and source URL
- Paper themes: **Carbon categorical** (`paper-clean`, `acl-clean`), **FT lineWeb** (`neurips-clean`, `nature-soft`)
- Web/dark themes: **Catppuccin Latte** (`shadcn-light`), **Catppuccin Mocha** (`shadcn-dark`, `poster-dark`)
- Catalog: [docs/palettes.md](../palettes.md)

## Upgrade from v0.1.2

- Re-render figures if you rely on exact series colors from built-in themes.
- Use `themes show <name> --json` to pin config; `monochrome-print` grayscale series are unchanged.
