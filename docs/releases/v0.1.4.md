# vega-paper v0.1.4

Documentation and rendering fixes: README figure gallery, correct rendering for specs with external CSV data, and agent skill docs that use the installed `vega-paper` CLI.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Pin this version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.1.4
```

### Supported platforms

| Asset | Platform |
|-------|----------|
| `vega-paper-0.1.4-darwin-arm64.tar.gz` | macOS Apple Silicon |
| `vega-paper-0.1.4-darwin-x64.tar.gz` | macOS Intel |
| `vega-paper-0.1.4-linux-x64.tar.gz` | Linux x64 |

Each tarball includes `vega-paper` and six Vega CLI shims. **Node.js** is required on the host (`doctor` checks it).

## Highlights

### README figure gallery (Phase 4d)

- Committed PNG previews under `docs/assets/gallery/` (8 themes + 6 examples)
- Theme grid in root README and example gallery in `examples/README.md`
- Regenerate: `bun run render:gallery` (maintainers)

### Render fix

- **`render`** now resolves relative `data.url` paths (e.g. `data.csv` next to a spec) when applying themes
- Fixes empty charts for infer-generated examples (training curves, boxplots, heatmaps, facets) in PNG/SVG/PDF output

### Agent skill and docs

- **`skills/vega-paper/SKILL.md`** — all examples use `vega-paper infer|lint|render|…` (not `bun run packages/cli/...`)
- Removed redundant skill script wrappers; call the CLI directly
- Repository docs aligned on installed CLI invocation

## Upgrade from v0.1.3

- Re-run `install.sh` or pin `--version 0.1.4` for the latest CLI binary.
- Re-render README gallery PNGs only if you customize themes or example specs (`bun run render:gallery`).
- If you relied on `skills/vega-paper/scripts/`, use `vega-paper lint` and `vega-paper render` instead.

## Breaking changes

None for CLI flags or theme names. Palette colors unchanged from v0.1.3.
