# vega-paper v0.1.0

First public release of VegaPaper — a CLI for publication-ready Vega-Lite figures in academic papers.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Add `~/.local/bin` to your PATH, then run `vega-paper doctor`.

### Supported platforms

| Asset | Platform |
|-------|----------|
| `vega-paper-0.1.0-darwin-arm64.tar.gz` | macOS Apple Silicon |
| `vega-paper-0.1.0-darwin-x64.tar.gz` | macOS Intel |
| `vega-paper-0.1.0-linux-x64.tar.gz` | Linux x64 |

Each tarball includes `vega-paper`, `vl2svg`, and `vg2svg`. **Node.js** is required on the host (checked by `doctor`).

Pin a version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.1.0
```

## Highlights

- **CLI:** `infer`, `render`, `lint`, `doctor`, `themes` — SVG output, figure meta sidecars
- **8 built-in themes:** paper, ACL, NeurIPS, shadcn, nature, monochrome print, poster
- **Lint profiles:** `paper`, `web`, `acl`, `print` (grayscale safety rules)
- **AI Skill:** `skills/vega-paper/` with references and validation/render scripts
- **Examples:** training curves, heatmaps, boxplots, theme samples

## Requirements

- Node.js (for Vega CLI binaries bundled in the tarball)
- Bun **not** required after install (compiled `vega-paper` binary)
