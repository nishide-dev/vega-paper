# vega-paper v0.1.5

New embedding scatter example for ML paper figures (t-SNE, UMAP, PCA projections), plus a gallery PNG preview in the examples index.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Pin this version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.1.5
```

### Supported platforms

| Asset | Platform |
|-------|----------|
| `vega-paper-0.1.5-darwin-arm64.tar.gz` | macOS Apple Silicon |
| `vega-paper-0.1.5-darwin-x64.tar.gz` | macOS Intel |
| `vega-paper-0.1.5-linux-x64.tar.gz` | Linux x64 |

Each tarball includes `vega-paper` and six Vega CLI shims. **Node.js** is required on the host (`doctor` checks it).

## Highlights

### Embedding scatter example

- New [`examples/embedding-scatter/`](../../examples/embedding-scatter/) — synthetic 2D points with class labels
- `vega-paper infer ... --chart scatter --x x --y y --color label` workflow documented for real UMAP/t-SNE CSV exports
- Regenerate spec: `bun run infer:embedding-scatter` (included in `infer:examples`)
- Gallery PNG: `docs/assets/gallery/examples/embedding-scatter.png`

### Docs

- [`examples/README.md`](../../examples/README.md) gallery and folder table updated
- [`skills/vega-paper/references/chart-selection.md`](../../skills/vega-paper/references/chart-selection.md) links scatter to the new example

## Upgrade from v0.1.4

- Re-run `install.sh` or pin `--version 0.1.5` if you want the latest release tag (no CLI behavior changes).
- Example-only release; existing `infer` scatter workflows are unchanged.

None.
