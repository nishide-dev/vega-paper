# vega-paper v0.1.2

PNG and PDF export for `render` and `infer`, plus custom theme JSON files from v0.1.1.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash
```

Pin this version:

```bash
curl -fsSL https://raw.githubusercontent.com/nishide-dev/vega-paper/main/scripts/install.sh | bash -s -- --version 0.1.2
```

### Supported platforms

| Asset | Platform |
|-------|----------|
| `vega-paper-0.1.2-darwin-arm64.tar.gz` | macOS Apple Silicon |
| `vega-paper-0.1.2-darwin-x64.tar.gz` | macOS Intel |
| `vega-paper-0.1.2-linux-x64.tar.gz` | Linux x64 |

Each tarball includes `vega-paper` and six Vega CLI shims (`vl2svg`, `vl2png`, `vl2pdf`, `vg2svg`, `vg2png`, `vg2pdf`). **Node.js** is required on the host (`doctor` checks it).

## Highlights

### Output formats (Phase 4.5)

- **`--format svg|png|pdf`** on `render` and `infer --out`
- **`--scale <factor>`** for PNG/PDF (Vega CLI `-s`; default `1`, max `32`)
- **SVG remains canonical** for papers; PDF for LaTeX, PNG for README/slides
- Figure meta records `format` and `scale` when applicable

```bash
vega-paper render chart.vl.json --format pdf --out figure.pdf
vega-paper render chart.vl.json --out figure.png --scale 2
```

### Custom themes (since v0.1.1)

- **`--theme path/to/theme.json`** or built-in preset name
- `themes show` accepts custom JSON files
- Example: [`examples/custom-theme/`](../../examples/custom-theme/)

## Upgrade from v0.1.1

- Install shims now include `vl2png` / `vl2pdf` / `vg2png` / `vg2pdf`; re-run `install.sh` or upgrade the Release tarball.
- Existing SVG workflows are unchanged.
